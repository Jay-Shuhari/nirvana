# Comment guide

The code uses tags that these extensions understand. Install them from the recommended list (VS Code shows a prompt when you open the folder).

| Tag in code | Meaning | Extension that shows it |
|---|---|---|
| `# ! text` | warning / security | Better Comments (red) |
| `# ? text` | why? question | Better Comments (blue) |
| `# * text` | important note | Better Comments (green) |
| `# TODO: text` | work to do | Todo Tree, TODO Highlight |
| `# FIXME:` / `# BUG:` | broken | Todo Tree, TODO Highlight |
| `# ANCHOR: Name` | jump point | Comment Anchors |
| `# STEP n:` | numbered step in a flow | Todo Tree |
| `- [ ]` in docs | open task | Todo Tree |
| `.tours/*.tour` | guided walkthrough | CodeTour |
| `docs/*.md` + `[[links]]` | notes graph | Foam, Markdown All in One, Markdown Preview Enhanced (diagrams) |
