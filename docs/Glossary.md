# Metis glossary

- **Academy** - the institution and its membership/eligibility policies.
- **Assignment** - a supervisor-authored task with instructions, materials, due time, rubric, and attempt limit.
- **Attempt** - a server-accepted submission for an assignment; each accepted attempt counts toward its limit, including evaluation failures.
- **Developer strengths** - versioned onboarding responses describing a student's current experience and interests.
- **Evidence** - repository paths/lines or other authorized material supporting an evaluation result.
- **GitHub App installation** - a user's explicit authorization allowing Metis server-side access to selected/all granted repositories; only fetched installation repositories are selectable.
- **Identity linking** - securely connecting a Google or GitHub identity to an existing Metis user after proving control of both.
- **Matriculation number** - the student's academy identifier, required during onboarding and unique within its configured academy scope.
- **Metis** - the product being rebuilt; Nirvana/DevTrace are legacy repository/code names.
- **Reference repository** - optional supervisor-authorized GitHub repository attached to an assignment and exposed read-only to enrolled students through Metis.
- **Rubric** - assignment criteria with enabled weights that total exactly 100.
- **Submission** - an accepted attempt to evaluate a selected repository commit against one assignment.
- **Override** - supervisor's replacement score, with a mandatory reason and audit trail.
- **RLS** - Row Level Security in Postgres; see [[Supabase-Security]] for legacy setup details.
- **Reminder** - assignment due email scheduled at the default 24h and 5h offsets, subject to student preferences.
