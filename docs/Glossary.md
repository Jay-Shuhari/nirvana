# Glossary
- **Rubric** - list of criteria with weights totalling 100.
- **Submission** - one evaluation of one commit.
- **Override** - supervisor's replacement score, with a mandatory reason.
- **Evidence** - the commits and files behind a score.
- **RLS** - Row Level Security in Postgres; see [[Supabase-Security]].
- **Pooler** - Supabase connection endpoint that works over IPv4.
